# 接福袋小游戏

## 项目说明
这是一个简单的网页小游戏，玩家通过移动接盘来接取掉落的福袋，不同类型的福袋有不同的分值。

## 部署说明
1. 确保所有文件使用正确的Content-Type
2. 在阿里云OSS中开启静态网站托管
3. 上传所有文件到OSS bucket根目录
4. 通过bucket域名或自定义域名访问游戏

## 文件结构
- index.html: 游戏主页面
- styles.css: 样式文件
- script.js: 游戏逻辑
- *.png: 游戏素材图片

## 注意事项
- 确保所有图片资源都已上传
- 确保文件路径正确
- 确保已开启OSS的公共读权限
